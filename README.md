# MIXN -DJ APP

## Overview

MIXN is a GUI audio application built using the JUCE framework. It has an intuitive and straightforward UX with a unique 2000s frutiger-metro style.

## Building

The app can be built through projucer (using the .juce file) or on any ARM mac you can download the packaged app
